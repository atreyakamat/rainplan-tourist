# RainPlan Tourist App Design Guidelines

## Design Principles
- Calm, reassuring UX during stressful rainy moments
- Fast decision flow with minimal cognitive load
- Friendly empty states and clear next actions

## Color Palette
- **Primary Blue:** `#1A56A0` (CTAs, active states)
- **Rain Grey:** `#6B7E8F` (secondary text, weather indicators)
- **Warm Amber:** `#F5A623` (highlights, badges)
- **Background:** `#F5F7FA`
- **Success Green:** `#27AE60`
- **Alert Red:** `#E74C3C`

## Typography
- Font family: Inter/Nunito equivalent system sans-serif
- H1: 24px bold
- H2: 20px bold
- H3: 16px semi-bold
- Body: 14px regular, line-height 1.6
- Minimum text size: 12px

## Components
- Weather bar should feel live and prominent at top
- Cards: radius 12px + subtle shadow
- Category chips as horizontal scroll
- Sticky booking sheet with 3-step action flow
- Tap targets should be 48px minimum where possible

## Screen Set (Tourist App)
1. Splash
2. Location permission
3. Sign-in choice
4. Time availability prompt
5. Home (rain-aware)
6. Explore (non-rain browsing)
7. Experience detail + booking
8. My Bookings
