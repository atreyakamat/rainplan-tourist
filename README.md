# RainPlan Tourist

RainPlan Tourist is a React Native (Expo) MVP focused on helping Goa tourists discover and book nearby indoor experiences quickly during rain.

## Included in this repository
- Tourist app MVP implementation (`App.tsx`)
- Tourist product requirements document (`docs/tourist-prd.md`)
- Tech stack document (`docs/tech-stack.md`)
- Design guidelines (`docs/design-guidelines.md`)

## Run locally
```bash
npm install
npm run start
```

## Type-check
```bash
npx tsc --noEmit
```
